# ROS2-SparkMAX-Archive
Archive of ROS2 nodes written to control SparkMAX motor controllers

I have a few REV Robotics Spark MAX motor controllers that I'm using to build a swerve drivetrain controlled by a RPI 4b rather than a RoboRIO. While searching for alternative ways to send CAN messages to these controllers that doesn't involve a Rio, I stumbled upon this package in some FRC Discord server. If anyone else needs to control SparkMAXes as well, I figured I might as well upload them to GitHub. I'm currently using them to develop much cleaner ROS2 nodes that are better documented, but until I finish and release that project, maybe these could help someone. These are made by Vanderbilt's robotics team, not me, and I've just put them here for reference.
